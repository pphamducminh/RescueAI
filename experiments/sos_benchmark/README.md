# Synthetic SOS development sample

`sample_100.jsonl` contains 100 synthetic Vietnamese SOS records generated offline with `--seed 412073`. The file separates private `ground_truth` from `generated_input` and includes train/dev/test labels. `sample_100.summary.json` records all design distributions and pending audit metadata. `sample_100.sha256` records the JSONL checksum.

This is a small, unaudited development sample, not a released or scored benchmark. See the [generator instructions](../../evaluation/sos_benchmark/README.md) and [dataset card](../../docs/DATASET_CARD.md) before using it.
