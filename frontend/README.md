# Frontend placeholder

The planned frontend is a React dashboard for SOS reports, team state, road conditions, proposed routes, explanations, and explicit dispatcher approval or rejection. It will distinguish proposals from approved assignments and show unreachable reports and uncertain extracted fields.

There is no React application or runnable dashboard in this scaffold. A later implementation should add its own package manifest, start command, and tests here. See [MVP Architecture v1](../docs/MVP%20Architecture%20v1.md) for the completed MVP requirements.
