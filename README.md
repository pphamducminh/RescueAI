# RescueAI

AI-powered decision-support system for disaster rescue coordination.

## Overview

RescueAI processes emergency SOS reports, assesses structured risk information,
optimizes rescue-team assignment, and dynamically replans routes when road
conditions change.

## Core Pipeline

SOS Report
→ AI Information Extraction
→ Priority Assessment
→ Dynamic Road Graph
→ Rescue Team Assignment
→ Route Optimization
→ Human Dispatcher Approval

## Main Components

- AI SOS Analysis
- Dynamic Road Graph
- Rescue Optimization
- Simulation
- Evaluation
- Emergency Dashboard
